Contributing to FishTracker
============================

See `CONTRIBUTING.md <https://github.com/Dilshan-Pathirana/Fish_tracking/blob/main/CONTRIBUTING.md>`_ in the repository root for detailed contribution guidelines.

Quick Summary
~~~~~~~~~~~~~

1. Fork the repository
2. Create a feature branch: ``git checkout -b feature/your-feature``
3. Follow PEP 8 and add docstrings to all functions
4. Add tests for new functionality
5. Run checks:

   .. code-block:: bash

      black .
      flake8 .
      mypy .
      pytest tests/

6. Create a pull request with a clear description

We welcome:
   - Bug reports and fixes
   - Feature suggestions and implementations
   - Documentation improvements
   - Test coverage expansion
   - Performance optimizations
